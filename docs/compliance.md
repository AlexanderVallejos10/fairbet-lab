# Compliance breve

FairBet Lab es una plataforma educativa con moneda virtual. No usa dinero real, no conecta pasarelas de pago y no hace retiros bancarios.

## Qué cubre
- Registro de usuario.
- DNI peruano básico.
- Validación de mayoría de edad.
- Estados de cuenta.
- Wallet con partida doble.
- Apuestas simples.
- Juego responsable.
- Auditoría por hash.
- Dashboard básico.

## Qué no cubre
- Identidad real verificada.
- Dinero real.
- Pagos reales.
- Fraude avanzado.
- Producción real para operar apuestas comerciales.

## Nota
El proyecto está hecho como simulador educativo.  
No constituye una casa de apuestas.
