# ADR 0010 - Alcance del MVP

## Contexto
El proyecto puede crecer mucho si se intenta todo a la vez.

## Opciones
1. Hacer todo.
2. Hacer primero lo esencial.

## Decisión
Se eligió el núcleo esencial.

## Consecuencias
- El proyecto termina mejor.
- La defensa es más clara.
- Quedan mejoras para una versión futura.
