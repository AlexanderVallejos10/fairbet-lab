# ADR 0006 - Juego responsable

## Contexto
El sistema debe tener límites de depósito y autoexclusión.

## Opciones
1. No incluir control.
2. Incluir límites y autoexclusión.

## Decisión
Se eligieron límites y autoexclusión.

## Consecuencias
- El usuario tiene más control.
- El proyecto cubre una parte importante del reto.
