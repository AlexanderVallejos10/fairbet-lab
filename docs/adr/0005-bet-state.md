# ADR 0005 - Estados de Bet

## Contexto
La apuesta necesita un flujo claro.

## Opciones
1. Un solo estado.
2. Varios estados.

## Decisión
Se eligieron estados: pending, accepted, won, lost, cancelled y cashed_out.

## Consecuencias
- La apuesta se entiende mejor.
- La liquidación es más ordenada.
